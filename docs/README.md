# Sentinel Mini 說明文件

Sentinel Mini 是本機執行的 Python 網站設定檢查原型。它讓 Codex 規劃與分析，由 Python 工具檢查指定頁面的安全標頭、Cookie 與 HTTPS 連線，再以獨立請求確認設定觀察是否可重現。

你可以在繁體中文介面查看任務、證據與歷史紀錄，也可以匯出 Markdown 或 JSON 報告。內建網站提供設定缺口與修正版本，規則模式不需要模型服務，適合先了解流程與輸出。

先閱讀[使用說明書](使用說明書.md)的專案介紹、主要功能與預期成果，再進入操作步驟。教學會帶你檢查內建網站、比對修正頁面，最後匯出報告。

文件以來源專案在 2026-11-17 的實作為準。說明書是操作教學，操作指南處理具體任務，參數頁供查詢，流程頁則解釋設計理由。模型與網站回應會隨使用環境改變，因此文件只對內建網站的規則模式列出固定預期結果。

## 文件如何核對

已對照 `app.py`、`sentinel/network.py`、`sentinel/checks.py`、兩種模型 adapter、前端文字與打包腳本，核對指令、參數、狀態及資料位置。這次文件工作沒有重跑真實模型或 HTTPS 憑證測試，歷史測試結果集中在設計與驗證紀錄。

本次使用 `write-docs` 與 `clarity` 的寫作規範，並核對本機文件連結。未執行未提供的 `/flagrare:editorial-pass`、`/flagrare:staleness-audit` 或其他 companion 工具。這次沒有修改程式或既有 ZIP；打包腳本目前不收錄 `docs/`，分享文件時需另外附上此目錄。

# Sentinel Mini 參數與結果參考

需要查預設值、理解狀態，或核對報告欄位時，直接查下面對應的表格。第一次使用請從[使用說明書](使用說明書.md)開始；具體操作與排錯見[操作指南](操作指南.md)。

本頁依專案目前的程式實作整理，文件日期為 2026-11-17。`pyproject.toml` 的版本為 1.0.0，定位為本機教學原型。

## 執行模式

| 介面模式 | CLI 寫法 | 規劃與分析 | 需要的條件 |
| --- | --- | --- | --- |
| Codex AI · 沿用本機登入 | `--target URL --authorized --ai` | Codex CLI | CLI 已安裝、登入與模型可用 |
| 規則模式 · 免模型示範 | `--target URL --authorized` | 固定規則，無 AI 呼叫 | Python 與可連線的目標 |
| 其他 AI · Compatible API | `--target URL --authorized --ai --backend compatible` | Compatible chat endpoint | 模型服務與環境變數已設定 |

Web 預設優先選 Codex，找不到 CLI 時會選規則模式。CLI 預設不呼叫模型，必須加 `--ai`。兩種入口的預設行為不同。

## 啟動參數

| 參數 | 預設值 | 用途 |
| --- | --- | --- |
| `--port` | `8765` | Web 操作介面的連接埠 |
| `--demo-port` | `8766` | Web 模式內建測試網站的連接埠 |
| `--no-browser` | 關閉 | 不自動開啟瀏覽器，服務仍會啟動 |
| `--target` | 未指定 | 指定後改走單次 CLI 檢查，不啟動 Web 或 demo |
| `--authorized` | 未確認 | CLI 目標授權確認；有 `--target` 時必須提供 |
| `--ai` | 關閉 | CLI 啟用模型；Web 模式由介面選項決定 |
| `--backend` | `codex` | CLI AI backend，可選 `codex` 或 `compatible` |
| `--goal` | 檢查網站安全標頭、TLS 與 Cookie 設定 | CLI 檢查目標文字，1-1000 字 |
| `--out` | 專案內 `data/latest.json` | CLI JSON 輸出路徑，同時寫入同名 `.md`，會覆寫既有檔案 |
| `--help` | 無 | 列出參數後結束 |

Web、demo 都只綁定 `127.0.0.1`，沒有提供對外綁定位址的參數。CLI 程式處理完 completed 回傳 0，partial 或 failed 回傳 1；參數解析失敗使用 argparse 的錯誤結束碼。

## 環境變數

| 變數 | 適用模式 | 說明 |
| --- | --- | --- |
| `SENTINEL_CODEX_BIN` | Codex | 選用的執行檔路徑，不接受 `.cmd`、`.bat`、`.ps1` |
| `SENTINEL_CODEX_MODEL` | Codex | 選用的模型名稱，未設定時使用 CLI 預設 |
| `SENTINEL_LLM_BASE_URL` | Compatible | 必填，例如本機服務的 `http://127.0.0.1:11434/v1` |
| `SENTINEL_LLM_MODEL` | Compatible | 必填的模型名稱 |
| `SENTINEL_LLM_API_KEY` | Compatible | 服務需要認證時才填；本機 Ollama 可不填 |

環境變數由目前程序讀取，沒有內建 `.env` 載入器。遠端 Compatible API 必須使用 HTTPS；僅 localhost、127.0.0.1、::1 可使用 HTTP。

## 目標網址

| 項目 | 限制或行為 |
| --- | --- |
| 網址格式 | 必須指定 `http://` 或 `https://` 與主機名稱 |
| 網址長度 | 最多 2048 字元 |
| 網址內容 | 不接受帳密、非空 query、非空 fragment、空白、控制字元或反斜線 |
| 位址範圍 | 拒絕 unspecified、multicast 與 link-local；可檢查授權的內網與 localhost |
| DNS 與連線 | 每次 audit 解析後固定使用第一個排序後的 IP，不自動切換其他 IP |
| 重新導向 | 保存 3xx 回應，不自動跟隨 |
| 讀取頁面 | 只對填入的路徑發 GET，不搜尋或爬取其他頁面 |

正規化後的目標會明列連接埠，例如輸入 `http://127.0.0.1:8766/` 時，報告會保留該連接埠。沒有指定連接埠時，HTTP 使用 80，HTTPS 使用 443。

## 任務狀態

| JSON 狀態 | 介面文字 | 意義 |
| --- | --- | --- |
| `queued` | 排隊中 | Web 已接受任務 |
| `planning` | 規劃中 | 驗證範圍並建立計畫 |
| `executing` | 執行中 | 工具執行與模型結果分析階段 |
| `verifying` | 確認中 | 獨立重測與最後摘要階段 |
| `completed` | 已完成 | 流程結束，沒有使任務降為 partial 的警告或失敗 |
| `partial` | 部分完成 | 有 warning、工具失敗或無法確認的 finding，已有資料仍保留 |
| `failed` | 失敗 | 流程無法完成，例如規劃或模型設定失敗 |
| `interrupted` | 已中斷 | 啟動時發現前次任務未結束，標記中斷且不自動重送 |

工具任務另使用 `queued`、`running`、`done`、`skipped`、`failed`。`done` 表示該工具執行結束，仍應閱讀 note 與證據；例如 TLS 驗證未成功時，工具可以完成紀錄而不產生漏洞 finding。

## 重測狀態

| 狀態 | 介面文字 | 判讀 |
| --- | --- | --- |
| `confirmed` | 可重現 | 獨立 GET 仍出現相同 code 與 Cookie 名稱的觀察 |
| `not_reproduced` | 未再現 | 新回應可供比較，但沒有出現同樣觀察 |
| `inconclusive` | 無法確認 | 重測連線失敗，或回應不適合比較 |

not_reproduced 只描述這次回應，不保證問題已永久修復。confirmed 也不表示攻擊成功。

## 工具與檢查規則

| action | 介面名稱 | 實際工作 |
| --- | --- | --- |
| `scan` | 網站掃描 | GET 指定頁面，檢查成功 HTML 回應的 CSP 與 nosniff |
| `command` | 執行指令 | HTTPS 時執行固定 Python TLS probe，HTTP 時略過 |
| `request` | 送出請求 | GET 同一頁面，檢查疑似工作階段 Cookie 屬性 |

| finding code | 觸發條件 |
| --- | --- |
| `csp_missing` | Content-Security-Policy 標頭不存在或為空 |
| `nosniff_missing` | X-Content-Type-Options 不等於 nosniff |
| `cookie_httponly` | 疑似工作階段 Cookie 缺少 HttpOnly |
| `cookie_secure` | 疑似工作階段 Cookie 缺少 Secure |
| `cookie_samesite` | 疑似工作階段 Cookie 未明確設定 SameSite |

以上規則只針對 HTTP 2xx 且 Content-Type 包含 `text/html` 的回應。Cookie 名稱含 session、auth、sid 或 token 才納入檢查，這是用途判斷的啟發式。finding severity 固定為 low，程式沒有實作完整 CVSS 評分。

TLS probe 回傳驗證是否成功、TLS 版本、cipher、憑證到期日與 subject/issuer，或失敗類型；目前沒有將 TLS 結果轉成獨立 finding 的重測規則。

## JSON 報告

| 頂層欄位 | 內容 |
| --- | --- |
| `id`、`target`、`goal` | 任務識別、正規化後目標及檢查說明 |
| `mode`、`backend`、`model` | 執行模式與模型資訊，`model` 視流程進度才出現 |
| `state` | 整體任務狀態 |
| `started_at`、`finished_at` | UTC 時間；未走到結束的快照可能沒有 finished_at |
| `scope` | 目標 authority、解析 IP、HTTP 請求上限及 redirect 設定，視流程進度才出現 |
| `tasks` | 各工具的 action、理由、狀態、note、證據 ID 與選用 AI 註解 |
| `evidence` | 實際 HTTP 或 TLS 證據 |
| `findings` | 設定觀察、修正建議、重測狀態與證據 ID |
| `events`、`warnings` | 階段紀錄及可見警告 |
| `summary`、`ai_summary` | 程式摘要與選用 AI 摘要，兩者分開儲存 |
| `model_calls` | 已計數的模型呼叫次數，開始呼叫即計入，不保證皆成功 |

HTTP 證據包含 `id`、`kind`、`time`、`url`、`method`、`status`、`headers`、`body`、`truncated`、`body_sha256` 與 `peer`。標頭以陣列保存，能保留多個 Set-Cookie；Cookie 值已遮蔽。本文最多保存 128 KiB，雜湊對應已擷取的原始片段，並非整份遠端文件。

TLS 證據包含證據 ID、種類、時間、固定 `argv` 與 `result`。finding 的 `evidence_ids` 連結原始觀察及可取得的重測證據。閱讀範例可開啟[已保存的 Codex JSON](../examples/codex-demo.json)與[Markdown 報告](../examples/codex-demo.md)。

Markdown 匯出提供證據索引，但不附上所有原始回應。需要稽核請保留 JSON；Web 的證據區也會顯示內容。

## 執行預算與資料位置

| 項目 | 目前值或位置 |
| --- | --- |
| Web 同時執行任務 | 1 個 audit |
| 工具 Worker | 最多 3 個並行 |
| 目標 HTTP 請求 | 每次 audit 最多 3 個 GET |
| 額外 TLS 連線 | 選取 command 且為 HTTPS 時 1 次 probe |
| 模型呼叫 | 最多 5 次，循序處理 |
| Codex 單次等待 | 最多 150 秒 |
| Compatible API 單次等待 | 45 秒 timeout |
| HTTP 讀取 | 本文預算 12 秒，socket timeout 6 秒，非整個任務的硬性總時限 |
| Web 歷史 | `data/runs.sqlite3`，側欄最多顯示最近 100 筆 |
| Codex 暫存 | `data/codex_calls/` 內單次目錄，呼叫結束後清理 |
| 瀏覽器匯出 | 由瀏覽器下載設定決定，不固定寫入專案 data |

HTTP 不跟隨 redirect、不帶登入 Cookie、不使用環境代理。程式會保存原始回應本文，只有特定標頭進行遮蔽。AI 接收目標、goal、遮蔽後標頭、TLS 資訊與觀察，不接收本文。

# Sentinel Mini 操作指南

已經完成[第一次檢查](使用說明書.md)後，可以依目前要做的事選擇下面的操作。所有命令都在包含 `app.py` 的專案根目錄執行；範例使用 PowerShell。

## 檢查你有權限的網站

先確認網站是你擁有或已取得檢查授權的目標，再在介面輸入完整的 HTTP 或 HTTPS 網址。你可以使用 `https://你的網域/公開頁面` 這類目標，不要填入帳密、查詢參數或 `#` 後的片段。

程式只請求你填入的頁面，不會登入或爬取其他頁面。如果網站以 301 或 302 導向別處，程式會保留該回應但不跟隨；請自行確認授權範圍，再填入最終網址建立新任務。

檢查目標文字用來提供規劃脈絡，例如「檢查公開首頁的安全標頭與工作階段 Cookie 設定」。工具能力仍限於既有三類 action，輸入其他攻擊要求不會增加工具功能。

## 避開已被占用的連接埠

若啟動時出現連接埠已被使用的錯誤，改用另一組號碼：

```powershell
python app.py --port 8865 --demo-port 8866
```

這時介面位於 `http://127.0.0.1:8865`，示範網站位於 `http://127.0.0.1:8866/`。按「填入本機測試網站」會帶入這次實際使用的網址，不需要修改程式。

如果只是不想自動開啟瀏覽器，加入 `--no-browser`，再自行前往終端顯示的介面網址。這個選項不會停止 Web 服務。

## 使用命令列輸出報告

使用內建測試網站時，先讓網頁版保持執行，再開另一個 PowerShell。下面的命令使用規則模式，不會呼叫模型：

```powershell
python app.py --target http://127.0.0.1:8766/ --authorized --out data/demo-first.json
```

完成後會同時產生 `data/demo-first.json` 與 `data/demo-first.md`。若要直接使用 Codex，另外加上 `--ai`：

```powershell
python app.py --target http://127.0.0.1:8766/ --authorized --ai --out data/demo-codex-first.json
```

CLI 不會自行啟動示範網站，也不會把結果加入網頁歷史。`--authorized` 是你對目標權限的明確確認；缺少這個參數，CLI 會停止。

每次請使用新的輸出檔名。CLI 的 `--out` 會覆寫同名 JSON 與對應的 Markdown；這和打包腳本拒絕覆寫 ZIP 的行為不同。PowerShell 可用 `$LASTEXITCODE` 查看結果，completed 為 0，partial 或 failed 為 1。

## 調整 Codex 設定

一般使用不必設定任何模型環境變數。若要指定模型，先在同一個 PowerShell 設定，再啟動程式：

```powershell
$env:SENTINEL_CODEX_MODEL = '你的帳戶可使用的模型名稱'
python app.py
```

若自動尋找執行檔失敗，可將 `SENTINEL_CODEX_BIN` 設為 Codex 原生執行檔的完整路徑。不要填 `.cmd`、`.bat` 或 `.ps1` 啟動包裝檔。設定會由啟動程式的程序讀取，修改後需要重新啟動 Sentinel Mini。

此專案使用 `--ignore-user-config` 呼叫 Codex，因此不會沿用個人的 provider、MCP 與 hooks 設定。它只沿用既有登入及程式提供的模型參數。若你的環境依賴自訂 provider，請先評估是否改用下一節的 Compatible API。

## 改接 Compatible API

這條路徑只在你已有其他模型服務時需要。服務必須支援 `/chat/completions`、system/user messages、`max_tokens`，並讓模型回傳 JSON。

以已啟動且已有模型的本機 Ollama 為例：

```powershell
$env:SENTINEL_LLM_BASE_URL = 'http://127.0.0.1:11434/v1'
$env:SENTINEL_LLM_MODEL = '你的已安裝模型名稱'
python app.py
```

在介面選「其他 AI · Compatible API」。遠端服務必須使用 HTTPS，若服務需要金鑰，再設定 `SENTINEL_LLM_API_KEY`。Base URL 應包含服務要求的版本路徑，不要再加 `/chat/completions`，程式會自行附加。

CLI 使用 `--ai --backend compatible`。程式不會自動安裝 Ollama、下載模型或載入 `.env`；環境變數必須存在於啟動它的終端。

## 備份網頁任務紀錄

先等目前任務結束，按 Ctrl+C 停止 Sentinel Mini，再複製 `data/runs.sqlite3` 到你的備份位置。若要保留自行匯出的報告，也一併複製相關 JSON 與 Markdown 檔案。

還原時，先停止程式，保留現有資料庫的副本，再將備份放回同一路徑。重新啟動後，未完成的舊任務會被標記 interrupted，不會自動恢復網路操作。

不要把整個 `data/` 當成可公開分享的範例。證據可能包含目標網站的本文與標頭；Cookie 值的遮蔽不代表所有敏感資料都已移除。

## 打包一份可分享的程式

先用唯讀預覽確認內容：

```powershell
python scripts/build_release.py --list
```

確認後，指定專案目錄外的新 ZIP 路徑：

```powershell
python scripts/build_release.py --output ../sentinel-mini-share-01.zip
```

若目的檔已存在，程式會拒絕覆寫，請改用新的名稱。打包只收錄程式指定的檔案，資料庫與環境檔不會加入；但程式原始碼仍需由你確認沒有寫入機密。

目前明確清單未包含 `docs/`。本說明書與開發日誌存在來源專案中，不會因為執行上述打包指令而自動進入 ZIP；分享時請另外附上需要的文件。本次撰寫文件沒有修改既有打包規則或重新產生舊 ZIP。

## 排除啟動與任務錯誤

| 看到的狀況 | 先檢查與處理 |
| --- | --- |
| 找不到 `python` | 確認 Python 3.11+ 可從目前終端執行；重新開啟終端後再試 |
| 找不到 `app.py` | 切換到解壓後含 `app.py` 的資料夾，或改用 `start.bat` |
| 介面無法連線 | 查看啟動終端是否仍在執行，並使用它顯示的實際連接埠 |
| 已偵測 Codex，但任務失敗 | 執行 `codex login status`；確認 CLI 版本與模型可用，必要時重新登入 |
| Codex 超過 150 秒 | 這次呼叫已停止等待，不會自動重試；服務恢復後另建任務 |
| 模型未回傳有效 JSON | 確認模型遵循結構化輸出及端點相容性；查看 warning，勿把 partial 當完整成功 |
| 請重新整理本機介面 | 重新整理頁面以取得目前服務的 request token，尤其是服務剛重啟時 |
| 已有任務執行中 | 等待目前任務結束；同一個 Web 服務一次只允許一個 audit |
| 目標 URL 不接受 | 移除帳密、query、fragment，並確認完整 scheme 與有效連接埠 |
| 預期有結果卻顯示零項 | 查看回應是否為成功 HTML、是否收到 redirect，以及 AI 是否選了該類任務 |
| HTTPS 工具無法確認 | 查看 TLS 證據中的失敗類型；連線失敗本身不等於已證明網站漏洞 |
| ZIP 拒絕覆寫 | 改用專案外的新 `.zip` 檔名，不必刪除原 ZIP |

如果仍無法判斷，保留任務狀態、warnings、工具 note 與已遮蔽的證據。分享錯誤時不要附上登入憑證、API Key 或未檢查過的整份資料庫。
